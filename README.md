# Keenetic NVR

Резервный видеорегистратор на Keenetic с Entware: кольцевой RTSP-архив (FFmpeg `-c copy`, MKV-сегменты по 900 секунд) с хранением не менее 72 часов на камеру, watchdog-восстановлением камер, опциональными уведомлениями (Telegram/webhook) и установщиками для миграции и чистой установки.

Документация и установка: [NVR/v2/README.md](NVR/v2/README.md).
