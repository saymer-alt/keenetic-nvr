# Как участвовать / Contributing

Спасибо за интерес к проекту **keenetic-nvr**. Исправления документации, отчёты с воспроизводимыми ошибками и небольшие целевые PR приветствуются.

## С чего начать

1. Прочитайте [README](README.md).
2. Перед новой задачей проверьте открытые Issues и Pull Requests, чтобы не дублировать работу.
3. Для ошибки создайте Issue через форму «Ошибка», для идеи — «Предложение»; свободный вопрос — обычным Issue.
4. Для изменения кода создайте отдельную ветку от актуальной `main` и PR с небольшим, обозримым diff.

## Правила для этого проекта

- Указывайте модель Keenetic, версию Entware/opkg, версию FFmpeg и модель камеры/NVR.
- Не публикуйте содержимое `/opt/etc/nvr-v2.conf`, токены Telegram, RTSP-пароли, полные выводы `ps` и фрагменты видеоархивов.
- Изменения сценариев записи, ротации и хранения требуют описания восстановления после сбоя.
- Не публикуйте реальные пароли, токены, подписки, VPN-ключи, WAN-адреса, приватные IP-инвентаризации и дампы конфигураций — обезличивайте.
- Не утверждайте, что проверяли физическое устройство, VPS или сеть, если такой проверки не было.
- Уважайте действующую лицензию и атрибуцию сторонних компонентов.

## Проверка PR

- Объясните **что** изменено, **почему** и как это проверено.
- Запустите подходящие проверки (CI или локально); если проверить нельзя, прямо укажите это.
- Не меняйте release-теги, защищённые ветки и исполняемую инфраструктуру в документационном PR.

## Безопасность

**Не сообщайте о нераскрытых уязвимостях публично через Issues.** Используйте приватный канал из [SECURITY.md](SECURITY.md). Конфигурации и логи перед публикацией обезличивайте.
