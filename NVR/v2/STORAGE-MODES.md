# Политики хранения NVR v2.5 (candidate)

Три режима определяют, **когда завершённые MKV могут быть удалены**. Все
удаления необратимы. Запись RTSP/FFmpeg и Telegram-бот выполняются отдельно.

| Режим | Когда удаляет | Минимальная глубина архива |
| --- | --- | --- |
| `time` | Только `mtime < now - NVR_RETENTION_SECONDS` | **Выбранные часы**; заполненный диск не разрешает раннее удаление |
| `circular` | Только при свободном месте ниже резерва; глобально от самого старого MKV | **Не гарантируется** |
| `hybrid` | По сроку и дополнительно при низком запасе места | **Не гарантируется**; заданные часы — *максимальный срок*, а не обязательная глубина |

Пока режимы прошли программные тесты. Аппаратная проверка **v2.5** на
Keenetic ещё не завершена, поэтому не распространяйте этот вариант как
подтверждённый для критически важных архивов.

## Совместимость со старым NVR

При отсутствии `NVR_STORAGE_MODE` используется `time`, 72 часа.
Открытый файл FFmpeg, непроверенные файловые дескрипторы и будущие
timestamp защищаются от удаления.

Строгий режим времени не удаляет файлы младше установленного периода,
**даже если диск полностью заполнен**: запись может остановиться, но
гарантия хранения для уже записанных сегментов не сокращается.
Значения можно задавать в пределах 1–87600 часов (максимум 10 лет).
Конфигурация существующего домашнего KN-1012 не меняется.

## Новая установка

Подготовьте Keenetic с Entware и отдельным **EXT4 USB-накопителем**.
В SSH выполните:

```sh
opkg update && opkg install curl && \
curl -fSsL https://raw.githubusercontent.com/saymer-alt/keenetic-nvr/main/setup.sh | sh
```

Мастер предложит TIME, CIRCULAR или HYBRID, часы и резерв места. При
выборе CIRCULAR/HYBRID потребует ввести слово `DELETE` — подтверждение,
что досрочное удаление разрешено.

* `TIME`: очистка по Cron ежечасно (`03 * * * *`).
* `CIRCULAR`/`HYBRID`: очистка по Cron каждые 5 минут.
* Watchdog камер во всех режимах проверяет запись каждые 5 минут.

**Внимание:** установка NVR v2.5 на чужом роутере должна выполняться после
прохождения CI и контрольного живого испытания. Новая функция находится
в состоянии candidate, пока нет подтверждения с устройства.

## Ручная конфигурация

Пример режима строгих 7 суток:

```sh
NVR_STORAGE_MODE='time'
NVR_RETENTION_SECONDS=604800
```

Режим кольцевой записи с резервом 10%, но не меньше 128 МБ:

```sh
NVR_STORAGE_MODE='circular'
NVR_DISK_FREE_RESERVE_PERCENT=10
NVR_DISK_FREE_MIN_MB=128
```

Гибридный режим: 14 суток сверху, но удаление возможно раньше:

```sh
NVR_STORAGE_MODE='hybrid'
NVR_RETENTION_SECONDS=1209600
NVR_DISK_FREE_RESERVE_PERCENT=10
NVR_DISK_FREE_MIN_MB=128
```

Используйте отдельный USB-диск под NVR: в режиме capacity заполнение
**другими файлами** тоже снижает свободное место, но NVR удаляет только
завершённые MKV из настроенных каталогов камер.

## Проверка перед удалением

```sh
sh /opt/etc/nvr-v2.sh status
sh /opt/etc/nvr-v2.sh cleanup --dry-run
```

`--dry-run` не удаляет видео и не меняет сохранённый статус очистки.
При полном диске это предварительный список кандидатов; фактический
результат может отличаться из-за файлов, растущих между проверкой
и очередной очисткой.

Telegram-команды `/status` и `/disk` показывают `STORAGE MODE`,
`RETENTION` и `FREE RESERVE`, когда они актуальны.

## Ограничения

- Кольцевой режим **не гарантирует** какого-либо числа часов, даже если
  в UI указан резерв 10%: это лишь целевой остаток места.
- Удаление допускается только для обычных сегментов `cam<ID>_*.mkv`;
  Symlink и текущий открытый файл защищены. Некорректный mount/RW,
  ошибка проверки процессов/файлов — повод остановить или пропустить
  удаление с ошибкой, а не стирать другой архив.
- Сегменты формируются каждые ~900 секунд (зависит от ключевых кадров).
  Если уже открытый сегмент не помещается в остаток свободного места,
  пользователь может потерять часть записи; режим не гарантирует запись
  на физически переполненный накопитель.
- В одной конфигурации используется **один RTSP хост и одни учётные данные**
  для набора каналов (например 101/201/301 одного устройства).
  Для независимых IP-камер с разными адресами/учётками требуется отдельное
  развитие проекта; см. `KNOWN-LIMITATIONS.md`.
- Не храните видеозаписи на системном разделе Entware.
